# FE101 starter

A complete, runnable TypeScript project — no placeholders.

## Run it (on the Windows machine, in PowerShell, inside this folder)

```powershell
node -v
npm install
npm run build
npm start
```

Expected output:

```text
ES change: 1.28%
Signal strong: true
High prices: 93.80 ▲, 94.10 ▲, 95.00 ▲
```

## Version note for the week of Oct 26, 2026

- Node 24 is the safe choice for FE101's first week: it was Active LTS until Oct 20, 2026 and remains supported until Apr 30, 2028.
- Node 26 becomes LTS on Oct 28, 2026 — two days after FE101 starts. Do not switch runtimes mid-first-week unless the course asks for it.
- Node 20 and older are end of life (Node 20 ended Apr 30, 2026). If `node -v` shows 20 or below, install Node 24 before class.
