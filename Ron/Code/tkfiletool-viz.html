Component Architecture

Data Flow

1 CLI args / GUI inputs → parse_arguments() sets ~30 instance attributes on Manipulate_files
2 GUI callbacks (do_hidden, do_type, do_size…) update the same self.p attributes in real time
3 run_search() → find_files() returns list[tuple(path, name, bsize, size_str, mod_time, hidden, lines, words, chars)]
4 Sorting applied on the list (alpha / size / mod / direction) before output
5 Output → flat list, tree view, or structured format (json/csv/yaml) via write_out()
