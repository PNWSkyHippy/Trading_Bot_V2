Tkinter Layout Tutorial — grid • pack • frames • sizing

Python 3.12 • plain tkinter/ttk • works on Windows and Mac • each example is a .py file in this folder — run it and drag the window around • click a section to open it

0. THE BIG PICTURE (read this first)

Everything in tkinter is a widget (Label, Button, Entry, Frame ...). Every widget has a parent — the first thing inside the brackets: tk.Label(parent, text="hi").
A widget does not appear until you tell a geometry manager where to put it. There are two you will use: grid (rows & columns, like a spreadsheet) and pack (stack things against the edges, like packing a suitcase).
Frame = an empty box. You use frames to cut the window into regions. Each frame is the parent of its own widgets and has its own grid or pack.
The one rule: inside any one parent, use grid OR pack — never both. (Part 2 explains why.)
Which one should I use? Use grid for anything that lines up in rows/columns (forms, whole-window layouts). Use pack for a simple row or column of things (a toolbar of buttons). When an AI gives you a mix: check each parent uses only one.
How to use this page: each step has a picture, the full script, and things to try. The picture is a real screenshot of that script. Every script is a separate file in this folder — run it, drag the window around, and edit it. Coloured frames are used on purpose so you can see the structure; in a real app you would drop the colours.
Cheat sheet at the bottom of the page.

1. GRID — rows and columns

1.1 — the grid in one picture   ex01_grid_basics.py

Think of the window as a table. rowconfigure / columnconfigure describe the table. .grid(row=, column=) puts a widget into one cell. weight = how much of the extra space a row/column gets when the window grows (0 = none, stays natural size). minsize = never thinner/shorter than this. sticky = which sides of the cell the widget glues to (n, s, e, w — "nsew" fills the whole cell; no sticky = floats in the middle at its natural size). columnspan/rowspan = cover several cells. padx/pady = empty space around the widget.

Try this (run it, then change it):
  • Look at the 2nd picture (window dragged bigger): the weight-0 column and row stayed put; the weight 1 and 2 columns shared the growth 1 : 2.
  • Change sticky="nsew" to sticky="n" on the blue box. It shrinks to its text and sticks to the top.
  • Set every weight to 0 and enlarge the window: nothing grows.
# ex01_grid_basics.py  -  GRID: rows, columns, weight, minsize, span, sticky
import tkinter as tk

root = tk.Tk()
root.title("ex01 - grid basics")
root.geometry("520x320")

# 1) Define the PAGE: 3 columns x 3 rows.
#    weight = how much EXTRA space this row/column gets when the window grows.
#    weight=0 (default) -> stays its natural size.   minsize = never smaller than this.
root.columnconfigure(0, weight=0, minsize=120)   # fixed-ish column
root.columnconfigure(1, weight=1)                # grows
root.columnconfigure(2, weight=2)                # grows twice as fast as column 1
root.rowconfigure(0, weight=0, minsize=50)       # header row: fixed height
root.rowconfigure(1, weight=1)                   # middle row: grows
root.rowconfigure(2, weight=0, minsize=40)       # bottom row: fixed height


def box(text, color):
    """Tiny helper: a coloured label so you can SEE each cell."""
    return tk.Label(root, text=text, bg=color, fg="black", relief="solid", bd=1)


# 2) Put things in cells.  sticky says how a widget fills its cell:
#    "n s e w" = stretch to touch that side.  "nsew" = fill the whole cell.
box("row0 col0", "#ffd166").grid(row=0, column=0, sticky="nsew")
box("row0 col1  columnspan=2", "#ef476f").grid(row=0, column=1, columnspan=2, sticky="nsew")
box("row1-2 col0  rowspan=2", "#06d6a0").grid(row=1, column=0, rowspan=2, sticky="nsew")
box("row1 col1  sticky=nsew", "#118ab2").grid(row=1, column=1, sticky="nsew", padx=4, pady=4)
box("row1 col2  sticky=nsew", "#9d8df1").grid(row=1, column=2, sticky="nsew", padx=4, pady=4)
box("row2 col1  no sticky (centred, natural size)", "#f4a261").grid(row=2, column=1)
box("row2 col2  sticky=w", "#e9c46a").grid(row=2, column=2, sticky="w")

root.mainloop()
Run it:  python ex01_grid_basics.py
1.2 — split the window into frames, then split a frame again   ex02_grid_subframes.py

Level 1: the window has a top bar, a sidebar and a body. Level 2: the body frame gets its own little grid. Notice the sub-frames A, B, C use body as their parent, so their row/column numbers start again at 0. This is the key trick: every frame is its own mini-window with its own grid.

Try this (run it, then change it):
  • The labels inside use pack — that's OK, because their parents (top, a ...) contain only pack widgets.
  • Change body row weights (1, 2) to (1, 1). Row C gets shorter.
  • Add padx=0, pady=0 to A, B, C and see the coloured gaps vanish.
# ex02_grid_subframes.py  -  GRID: split the window into frames, then split a frame again
import tkinter as tk

root = tk.Tk()
root.title("ex02 - grid with sub-frames")
root.geometry("640x400")

# ---- Level 1: the window (root) has 2 rows x 2 columns ----------------
root.columnconfigure(0, weight=0, minsize=160)   # sidebar: fixed width
root.columnconfigure(1, weight=1)                # content: takes the rest
root.rowconfigure(0, weight=0)                   # top bar: natural height
root.rowconfigure(1, weight=1)                   # body: takes the rest

top = tk.Frame(root, bg="#ef476f", height=50)
side = tk.Frame(root, bg="#06d6a0")
body = tk.Frame(root, bg="#118ab2")

top.grid(row=0, column=0, columnspan=2, sticky="ew")     # spans both columns
side.grid(row=1, column=0, sticky="ns")                  # full height
body.grid(row=1, column=1, sticky="nsew")                # fills everything left

# ---- Level 2: split the BODY frame into its own grid -------------------
# NOTE: these use  body  as the parent, not root.  body has its own rows/columns.
body.columnconfigure(0, weight=1)
body.columnconfigure(1, weight=1)
body.rowconfigure(0, weight=1)
body.rowconfigure(1, weight=2)

a = tk.Frame(body, bg="#ffd166")
b = tk.Frame(body, bg="#f4a261")
c = tk.Frame(body, bg="#e9c46a")
a.grid(row=0, column=0, sticky="nsew", padx=6, pady=6)
b.grid(row=0, column=1, sticky="nsew", padx=6, pady=6)
c.grid(row=1, column=0, columnspan=2, sticky="nsew", padx=6, pady=6)

# ---- Labels so you can see what is what --------------------------------
tk.Label(top, text="TOP (root row 0, columnspan 2)", bg="#ef476f").pack(pady=14)
tk.Label(side, text="SIDE\n(root row 1, col 0)", bg="#06d6a0").pack(padx=10, pady=10)
tk.Label(a, text="A  (body 0,0)", bg="#ffd166").pack(expand=True)
tk.Label(b, text="B  (body 0,1)", bg="#f4a261").pack(expand=True)
tk.Label(c, text="C  (body row 1, columnspan 2)", bg="#e9c46a").pack(expand=True)

root.mainloop()
Run it:  python ex02_grid_subframes.py
1.3 — real widgets: Label, Entry, Combobox, Button, Listbox, Treeview, Text   ex03_grid_widgets.py

A form frame (labels in column 0 right-aligned with sticky="e", inputs in the next column stretched with sticky="ew"), a data frame with a Listbox and a Treeview side by side, and a Text box at the bottom. Scrollbars are just another widget placed in the next column with sticky="ns", wired with command= and yscrollcommand=.

Try this (run it, then change it):
  • Entries only stretch because their column has weight=1 and they are sticky="ew". You need both.
  • Buttons in one row = same row=, different column=. Linear list = same column=, different row=.
  • Remove weight=1 from form.columnconfigure(1, ...) and the entries stop growing.
# ex03_grid_widgets.py  -  GRID with real widgets: Label, Entry, Combobox, Button,
#                          Listbox, Treeview, Text (+ scrollbars)
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("ex03 - grid with real widgets")
root.geometry("720x520")
root.columnconfigure(0, weight=1)
root.rowconfigure(1, weight=1)

# ---------- Frame 1: a FORM (labels left, inputs right) ----------------
form = tk.LabelFrame(root, text=" form frame ", bg="#fff3cd", padx=8, pady=8)
form.grid(row=0, column=0, sticky="ew", padx=8, pady=8)
form.columnconfigure(1, weight=1)          # the Entry column stretches
form.columnconfigure(3, weight=1)

ttk.Label(form, text="Name:").grid(row=0, column=0, sticky="e", padx=4, pady=4)
ttk.Entry(form).grid(row=0, column=1, sticky="ew", padx=4, pady=4)

ttk.Label(form, text="Type:").grid(row=0, column=2, sticky="e", padx=4, pady=4)
combo = ttk.Combobox(form, values=["Stock", "Crypto", "Futures"], state="readonly")
combo.current(0)
combo.grid(row=0, column=3, sticky="ew", padx=4, pady=4)

ttk.Label(form, text="Notes:").grid(row=1, column=0, sticky="e", padx=4, pady=4)
ttk.Entry(form).grid(row=1, column=1, columnspan=3, sticky="ew", padx=4, pady=4)

# buttons in a row, linear (all row 2, columns 0..)
ttk.Button(form, text="Add").grid(row=2, column=1, sticky="w", padx=4, pady=4)
ttk.Button(form, text="Clear").grid(row=2, column=2, padx=4, pady=4)

# ---------- Frame 2: three data widgets side by side -------------------
data = tk.Frame(root, bg="#d1e7dd")
data.grid(row=1, column=0, sticky="nsew", padx=8, pady=(0, 8))
data.columnconfigure(0, weight=1)          # listbox
data.columnconfigure(2, weight=3)          # treeview (3x wider)
data.rowconfigure(0, weight=1)

# Listbox + its scrollbar (scrollbar sits in the NEXT column, sticky ns)
lb = tk.Listbox(data, width=14)
for i in range(1, 31):
    lb.insert("end", f"item {i}")
lb_sb = ttk.Scrollbar(data, orient="vertical", command=lb.yview)
lb.configure(yscrollcommand=lb_sb.set)
lb.grid(row=0, column=0, sticky="nsew")
lb_sb.grid(row=0, column=1, sticky="ns")

# Treeview + its scrollbar
tree = ttk.Treeview(data, columns=("sym", "qty", "px"), show="headings", height=8)
for col, w in (("sym", 80), ("qty", 60), ("px", 80)):
    tree.heading(col, text=col.upper())
    tree.column(col, width=w)
for n in range(20):
    tree.insert("", "end", values=(f"SYM{n}", n * 10, f"{100 + n:.2f}"))
tr_sb = ttk.Scrollbar(data, orient="vertical", command=tree.yview)
tree.configure(yscrollcommand=tr_sb.set)
tree.grid(row=0, column=2, sticky="nsew", padx=(8, 0))
tr_sb.grid(row=0, column=3, sticky="ns")

# ---------- Frame 3: Text box with scrollbar ---------------------------
logf = tk.Frame(root, bg="#cfe2ff")
logf.grid(row=2, column=0, sticky="ew", padx=8, pady=(0, 8))
logf.columnconfigure(0, weight=1)
txt = tk.Text(logf, height=5, wrap="word")
txt.insert("1.0", "A Text widget: type here.\n" * 8)
tx_sb = ttk.Scrollbar(logf, orient="vertical", command=txt.yview)
txt.configure(yscrollcommand=tx_sb.set)
txt.grid(row=0, column=0, sticky="nsew")
tx_sb.grid(row=0, column=1, sticky="ns")

root.mainloop()
Run it:  python ex03_grid_widgets.py

2. PACK — stack against the edges

2.1 — side, fill, expand, anchor, padx, pady   ex04_pack_basics.py

pack has no rows or columns. Each widget takes a slice off one edge of the remaining space, in the order you pack them. side = which edge (top / bottom / left / right). fill = stretch across the slice (x, y or both). expand=True = claim any space nobody else wanted. anchor = where to sit if the slice is bigger than the widget (n, ne, e ... ). padx/pady = space outside; ipadx/ipady = space inside.

Try this (run it, then change it):
  • Order matters. Move the 'side=bottom' line above the first one: the layout changes.
  • Remove expand=True from the blue box: it no longer grows when you drag the window bigger.
  • Pack the blue box last normally; widgets that need to be 'in the way' (bars, sidebars) go first.
# ex04_pack_basics.py  -  PACK: side, fill, expand, anchor, padx, pady
import tkinter as tk

root = tk.Tk()
root.title("ex04 - pack basics")
root.geometry("560x360")


def box(parent, text, color):
    return tk.Label(parent, text=text, bg=color, relief="solid", bd=1)


# pack works like stacking: each widget grabs a SLICE off the free space.
# Order matters!  First packed = first slice.

box(root, "1) side=top, fill=x   (stretches left-right)", "#ef476f").pack(side="top", fill="x")
box(root, "2) side=bottom, fill=x", "#ffd166").pack(side="bottom", fill="x")
box(root, "3) side=left, fill=y\n(stretches up-down)", "#06d6a0").pack(side="left", fill="y")

# expand=True : "give me any leftover space".  fill says how to use it.
box(root, "4) side=left, fill=both, expand=True\n(grabs ALL leftover space)", "#118ab2").pack(
    side="left", fill="both", expand=True, padx=10, pady=10)   # padx/pady = space OUTSIDE

# anchor : where the widget sits inside a slice that is bigger than it needs.
box(root, "5) side=top, anchor=ne", "#f4a261").pack(side="top", anchor="ne")
box(root, "6) side=top, anchor=w", "#e9c46a").pack(side="top", anchor="w", ipadx=20, ipady=8)  # ipad = padding INSIDE

root.mainloop()

2.2 — the same layout as 1.2, done with pack   ex05_pack_layout.py

Same look as the grid version. Compare: with grid you say where (row 1, column 0); with pack you say which edge, in order. To get 'A beside B' you need a helper frame (row) packed side=left for both. Pack is great for simple lines, but grids are easier when things must line up in two directions.

Try this (run it, then change it):
  • A Frame shrinks to fit its contents, so width=160 on the side panel is ignored unless you call pack_propagate(False) (see Part 4). Comment that line out and see.
  • Make the window smaller: with pack, the widgets packed last get squeezed or clipped first.
# ex05_pack_layout.py  -  the SAME layout as ex02, built with PACK
#   top bar across the window, a sidebar on the left, a body filling the rest,
#   and the body split into 2 frames side by side with one underneath.
import tkinter as tk

root = tk.Tk()
root.title("ex05 - pack layout")
root.geometry("640x400")

# Level 1  (order = top first, then left, then the body LAST with expand)
top = tk.Frame(root, bg="#ef476f", height=50)
top.pack(side="top", fill="x")

side = tk.Frame(root, bg="#06d6a0", width=160)
side.pack(side="left", fill="y")

body = tk.Frame(root, bg="#118ab2")
body.pack(side="left", fill="both", expand=True)

# Level 2 inside body: a "row" frame holding A and B, then C underneath
row = tk.Frame(body, bg="#118ab2")
row.pack(side="top", fill="both", expand=True)

a = tk.Frame(row, bg="#ffd166")
b = tk.Frame(row, bg="#f4a261")
a.pack(side="left", fill="both", expand=True, padx=6, pady=6)
b.pack(side="left", fill="both", expand=True, padx=6, pady=6)

c = tk.Frame(body, bg="#e9c46a", height=120)
c.pack(side="top", fill="both", expand=True, padx=6, pady=6)

tk.Label(top, text="TOP  (pack side=top, fill=x)", bg="#ef476f").pack(pady=14)
tk.Label(side, text="SIDE\n(side=left, fill=y)", bg="#06d6a0").pack(padx=10, pady=10)
tk.Label(a, text="A", bg="#ffd166").pack(expand=True)
tk.Label(b, text="B", bg="#f4a261").pack(expand=True)
tk.Label(c, text="C  (under A and B)", bg="#e9c46a").pack(expand=True)

# A pack gotcha: the side panel has width=160 but its Label is small.
# A Frame SHRINKS to fit its children, so width=160 would be ignored!
# Fix:  side.pack_propagate(False)   (more on this in ex10)
side.pack_propagate(False)

root.mainloop()

2.3 — why you can't mix grid and pack in the same parent   ex06_mixing_error.py

Both managers try to decide the size of their parent. If the parent has widgets from grid and from pack, each one resizes the parent to suit itself, which triggers the other, which triggers... forever. So tkinter refuses with the error shown. (In some older cases it just froze the app.) The error message says exactly what's wrong: "cannot use geometry manager pack inside . which already has slaves managed by grid" — . is the main window.

Try this (run it, then change it):
  • This script catches the error so you can read it. Remove the try/except to see the real crash.
  • When you get this error, find the two lines with the same parent but different managers.
# ex06_mixing_error.py  -  WHAT GOES WRONG when you mix grid and pack in ONE parent
import tkinter as tk

root = tk.Tk()
root.title("ex06 - mixing grid and pack (the mistake)")
root.geometry("520x220")

first = tk.Label(root, text="I used GRID in root", bg="#06d6a0")
first.grid(row=0, column=0)

second = tk.Label(root, text="I tried PACK in root", bg="#ef476f")
msg = ""
try:
    second.pack()          # <-- same parent (root) already uses grid -> ERROR
except tk.TclError as err:
    msg = str(err)

tk.Label(root, text="Python said:", font=("TkDefaultFont", 10, "bold")).grid(row=1, column=0, sticky="w", pady=(20, 0))
tk.Label(root, text=msg, fg="#b00020", wraplength=480, justify="left").grid(row=2, column=0, sticky="w")

# (If tkinter did NOT raise an error you could get an endless "freeze":
#  grid and pack keep resizing the window to please each other. Never mix.)

root.mainloop()

2.4 — how to mix them safely: one manager per parent   ex07_mixing_safely.py

Put each group in its own Frame. The window uses pack for two big frames; the toolbar frame uses pack for buttons; the form frame uses grid for the labels and entries. Different parents → no conflict. You can nest as deep as you like.

Try this (run it, then change it):
  • To check any widget: read its first argument. ttk.Button(toolbar, ...).pack() → parent is toolbar → toolbar's children must all use pack.
  • Try changing one toolbar button to .grid(...) and see the error from 2.3 appear.
# ex07_mixing_safely.py  -  the RIGHT way: each PARENT uses only ONE manager.
#   root          -> uses pack   (top bar, then the rest)
#   toolbar frame -> uses pack   (buttons in a row)
#   form frame    -> uses grid   (labels + entries lined up)
# A different parent may use a different manager. Only one manager PER PARENT.
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("ex07 - mixing safely")
root.geometry("520x300")

# ---- root: PACK only ----
toolbar = tk.Frame(root, bg="#ffd166")
toolbar.pack(side="top", fill="x")
form = tk.Frame(root, bg="#d1e7dd")
form.pack(side="top", fill="both", expand=True)

# ---- toolbar: PACK only (children of toolbar) ----
for name in ("New", "Open", "Save"):
    ttk.Button(toolbar, text=name).pack(side="left", padx=4, pady=4)
ttk.Button(toolbar, text="Quit", command=root.destroy).pack(side="right", padx=4, pady=4)

# ---- form: GRID only (children of form) ----
form.columnconfigure(1, weight=1)
rows = ["First name", "Last name", "Email"]
for r, label in enumerate(rows):
    tk.Label(form, text=label + ":", bg="#d1e7dd").grid(row=r, column=0, sticky="e", padx=8, pady=6)
    ttk.Entry(form).grid(row=r, column=1, sticky="ew", padx=8, pady=6)

# Rule of thumb: when you write  X.grid(...)  or  X.pack(...)  look at the FIRST
# word inside the brackets of X = Widget(PARENT, ...).  Every child of the same
# PARENT must use the same method.

root.mainloop()

3. DESIGN ON PAPER FIRST

The 5-step method
1. Sketch the window as boxes. Draw only the big regions first.
2. Draw grid lines through the sketch. Count the rows and columns. A box that crosses several lines = columnspan / rowspan.
3. Decide what stretches: mark each row and column "fixed" (weight 0) or "grows" (weight 1, 2 ...). The main work area grows; bars and sidebars usually don't.
4. Code the skeleton: just coloured empty Frames (ex08). Check it looks like the sketch and stretches properly.
5. Fill each frame: for every frame do steps 1–3 again, inside it (ex09). Frames inside frames, each with its own small grid.
   +--------------------------------------------+
   |                  TOP BAR                   |   row 0 : columnspan=3
   +----------+-----------------+---------------+
   |          |                 |               |
   |   LEFT   |     MIDDLE      |     RIGHT     |   row 1 : grows
   |  (1/4)   |     (1/4)       |     (2/4)     |
   +----------+-----------------+---------------+
     col 0       col 1             col 2
     weight 1    weight 1          weight 2      (uniform="cols" makes it exact)
3.1 — step 4: the skeleton, frames only   ex08_paper_skeleton.py

The sketch above, as code. The top bar spans all 3 columns (columnspan=3); the three panels sit in row 1. uniform="cols" on the columns makes them share width exactly 1 : 1 : 2 (otherwise weights only split the extra space, so bigger contents make a column wider than you meant).

Try this (run it, then change it):
  • Stretch the window: the top bar keeps its height, panels grow, widths stay 1/4, 1/4, 1/2.
  • Remove uniform="cols" and compare the widths.
# ex08_paper_skeleton.py  -  from a PAPER SKETCH to code, step 1: just the frames
#
#   +--------------------------------------------+
#   |                  TOP BAR                   |   row 0, spans all 3 columns
#   +----------+-----------------+---------------+
#   |          |                 |               |
#   |  LEFT    |    MIDDLE       |    RIGHT      |   row 1
#   |  (1/4)   |    (1/4)        |    (2/4)      |
#   +----------+-----------------+---------------+
#
# Count the rows and columns on your sketch -> that is your grid.
import tkinter as tk

root = tk.Tk()
root.title("ex08 - paper skeleton")
root.geometry("800x450")

# uniform="x" makes columns share space in EXACT proportion to their weights
# (without it, weight only divides the EXTRA space, so widths can look uneven).
root.columnconfigure(0, weight=1, uniform="cols")   # 1 part  = 1/4
root.columnconfigure(1, weight=1, uniform="cols")   # 1 part  = 1/4
root.columnconfigure(2, weight=2, uniform="cols")   # 2 parts = 2/4
root.rowconfigure(0, weight=0)                      # top bar keeps its height
root.rowconfigure(1, weight=1)                      # panels take the rest

topbar = tk.Frame(root, bg="#ef476f", height=60)
left = tk.Frame(root, bg="#06d6a0")
middle = tk.Frame(root, bg="#ffd166")
right = tk.Frame(root, bg="#118ab2")

topbar.grid(row=0, column=0, columnspan=3, sticky="nsew")
left.grid(row=1, column=0, sticky="nsew")
middle.grid(row=1, column=1, sticky="nsew")
right.grid(row=1, column=2, sticky="nsew")

for frame, name in ((topbar, "TOP BAR"), (left, "LEFT 1/4"), (middle, "MIDDLE 1/4"), (right, "RIGHT 2/4")):
    tk.Label(frame, text=name, bg=frame["bg"], font=("TkDefaultFont", 12, "bold")).place(relx=0.5, rely=0.5, anchor="center")

root.mainloop()
Run it:  python ex08_paper_skeleton.py
3.2 — step 5: controls in the panels, looking right when stretched   ex09_paper_filled.py

Each panel is its own little grid. Patterns used:

  • Top bar: title in column 0, an empty column with weight=1 (a spring), buttons in columns 2 and 3 → buttons stay at the right edge.
  • Left: one column, weight=1, buttons sticky="ew" → all the same width.
  • Middle: labels sticky="e", entries sticky="ew" → a tidy form.
  • Right: the Treeview row has weight=1 and the scrollbar sits beside it.
Padding tip: padx/pady go on widgets and are fixed pixel gaps, so they look the same at any window size. Use an asymmetric pair like padx=(8, 4) (left, right) so gaps between neighbouring panels don't double up.

Try this (run it, then change it):
  • Compare the three pictures: the gaps stay the same, only the table grows.
  • Drag the window as small as it will go: root.minsize(600, 320) stops it before things get squashed.
# ex09_paper_filled.py  -  paper sketch step 2: controls inside each panel, stretch-friendly
#   Try it: drag the window bigger and smaller.  Notice what grows and what doesn't.
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("ex09 - paper design, filled in")
root.geometry("820x460")
root.minsize(600, 320)                        # can't shrink below this (see ex12)

root.columnconfigure(0, weight=1, uniform="cols")
root.columnconfigure(1, weight=1, uniform="cols")
root.columnconfigure(2, weight=2, uniform="cols")

4. SIZES, CHOPPING AND SHRINKING

Where does the window's size come from?
• If you call root.geometry("800x600"), that is the size. Done.
• If you don't, the window is exactly big enough for its contents. Same for every Frame: a frame shrink-wraps its children. This is called propagation.
• Frame(width=300, height=100) is therefore ignored if the frame has children (or uses grid/pack inside). To force a size: frame.pack_propagate(False) (if its children use pack) or frame.grid_propagate(False) (if they use grid).
• Once a frame has a forced size, anything that doesn't fit is cut off silently — no error.
4.1 — size to fit — and propagate on/off   ex10_size_to_fit.py

Three frames all asked for a size. The red one has propagation on (default) and ignores the request. The green one and the yellow one turn it off and obey. winfo_reqwidth() / winfo_reqheight() tell you what size the window wants (printed in the terminal).

Try this (run it, then change it):
  • Which method? Look at how the frame's children are placed: pack → pack_propagate(False), grid → grid_propagate(False).
  • Add root.geometry("900x500") before mainloop(): now the window size is yours, not the contents'.
# ex10_size_to_fit.py  -  how big is a window / frame if you DON'T set a size?
#   Answer: exactly big enough for its contents.  Frames SHRINK-WRAP their children.
#   (called "propagation").  Turn it off with pack_propagate(False) / grid_propagate(False).
import tkinter as tk

root = tk.Tk()
root.title("ex10 - size to fit  (no root.geometry() call!)")

# LEFT: a frame asks for width=300,height=120 but has a small label in it
# and propagation is ON (default) -> frame IGNORES 300x120, shrink-wraps the label.
f1 = tk.Frame(root, bg="#ef476f", width=300, height=120)
f1.grid(row=0, column=0, padx=10, pady=10)
tk.Label(f1, text="propagate ON (default)\nwidth/height ignored").pack()

# RIGHT: same, but propagation OFF -> frame obeys width/height.
f2 = tk.Frame(root, bg="#06d6a0", width=300, height=120)
f2.grid(row=0, column=1, padx=10, pady=10)
f2.pack_propagate(False)          # f2's children use pack -> pack_propagate(False)
tk.Label(f2, text="propagate OFF\nsize is 300x120").pack()

# BOTTOM: a frame whose children use GRID needs grid_propagate(False) instead.
f3 = tk.Frame(root, bg="#ffd166", width=620, height=60)
f3.grid(row=1, column=0, columnspan=2, padx=10, pady=(0, 10))
f3.grid_propagate(False)          # f3's children use grid -> grid_propagate(False)
tk.Label(f3, text="grid_propagate(False): size is 620x60").grid(row=0, column=0, padx=10, pady=10)

# Ask what size the window wants:
root.update_idletasks()
print("window wants", root.winfo_reqwidth(), "x", root.winfo_reqheight())

root.mainloop()

4.2 — too many controls → chopped → scroll   ex11_chopped.py

Left: a fixed-size frame holds 12 buttons but only 7 fit, so Button 8–12 are invisible. Same thing happens when you shrink a window below what the contents need, or pack too many things in a fixed area. Right: the standard fix — put the controls in a Frame inside a Canvas, add a scrollbar. (Listbox, Treeview and Text already have scrolling built in: just attach a Scrollbar like in 1.3.)

Try this (run it, then change it):
  • Other fixes: make the window bigger, use fewer/smaller widgets, put things in columns instead of one tall stack, or use ttk.Notebook tabs.
  • Change height=200 to height=400 in the left frame: all 12 fit.
# ex11_chopped.py  -  TOO MANY CONTROLS: what gets chopped, and the fix
#   LEFT  window area: a fixed-size frame (propagate OFF) with 12 buttons -> bottom ones CUT OFF.
#   RIGHT window area: same 12 buttons, but in a scrollable Canvas -> scrollbar appears.
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("ex11 - chopped content")
root.geometry("640x300")
root.columnconfigure((0, 1), weight=1, uniform="c")
root.rowconfigure(1, weight=1)

tk.Label(root, text="CHOPPED  (fixed frame, 12 buttons)", fg="#b00020").grid(row=0, column=0, pady=4)
tk.Label(root, text="FIXED with a scrollable canvas", fg="#007a3d").grid(row=0, column=1, pady=4)

# ---------- LEFT: the chopped one ----------
chopped = tk.Frame(root, bg="#ef476f", width=280, height=200)
chopped.grid(row=1, column=0, sticky="n", padx=10, pady=4)
chopped.grid_propagate(False)             # frame stays 280x200 no matter what's inside
for i in range(12):
    ttk.Button(chopped, text=f"Button {i + 1}").grid(row=i, column=0, padx=6, pady=2)
# Buttons that don't fit are simply NOT SHOWN. No error, no warning.

# ---------- RIGHT: the scrollable one ----------
holder = tk.Frame(root)
holder.grid(row=1, column=1, sticky="nsew", padx=10, pady=4)
holder.columnconfigure(0, weight=1)
holder.rowconfigure(0, weight=1)

canvas = tk.Canvas(holder, bg="#d1e7dd", highlightthickness=0)
bar = ttk.Scrollbar(holder, orient="vertical", command=canvas.yview)
canvas.configure(yscrollcommand=bar.set)
canvas.grid(row=0, column=0, sticky="nsew")
bar.grid(row=0, column=1, sticky="ns")

inner = tk.Frame(canvas, bg="#d1e7dd")                   # put your widgets in THIS frame
canvas.create_window((0, 0), window=inner, anchor="nw")
for i in range(12):
    ttk.Button(inner, text=f"Button {i + 1}").grid(row=i, column=0, padx=6, pady=2)
# tell the canvas how big the inner frame really is, so it knows how far to scroll
inner.bind("<Configure>", lambda e: canvas.configure(scrollregion=canvas.bbox("all")))

root.mainloop()

4.3 — shrinking the window: minsize, sticky, weights   ex12_shrink.py

When the window gets smaller than the contents want, tkinter squeezes the growable parts first (rows/columns with weight > 0 that are sticky). Fixed parts (weight 0, with minsize) hold their size. Whatever still can't fit gets chopped from the bottom/right. So: give the main content area the weight, and set root.minsize() to a size where nothing important is cut.

Try this (run it, then change it):
  • root.minsize(w, h) = smallest allowed; root.maxsize(w, h) = biggest; root.resizable(False, False) = locked.
  • Comment out the minsize line and drag very small: the buttons at the bottom get cut off.
  • A widget with no sticky never stretches, even in a weight=1 cell.
# ex12_shrink.py  -  SHRINKING the window: what survives?  (minsize, sticky, weights)
#   Drag the window smaller and watch.  Then try removing the minsize line.
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("ex12 - shrinking")
root.geometry("640x340")
root.minsize(420, 240)          # the user can't drag smaller than this. (maxsize() also exists)
# root.resizable(False, False)  # or: forbid resizing completely

root.columnconfigure(0, weight=0, minsize=140)   # sidebar: never narrower than 140
root.columnconfigure(1, weight=1)                # content: absorbs all size changes
root.rowconfigure(1, weight=1)

top = tk.Frame(root, bg="#ef476f", height=40)
top.grid(row=0, column=0, columnspan=2, sticky="ew")
tk.Label(top, text="sticky='ew': stretches sideways only", bg="#ef476f").pack(pady=8)

side = tk.Frame(root, bg="#06d6a0")
side.grid(row=1, column=0, sticky="ns")           # sticky ns: tall but NOT wide
tk.Label(side, text="minsize=140\nweight=0", bg="#06d6a0").pack(padx=10, pady=10)

content = tk.Frame(root, bg="#118ab2")
content.grid(row=1, column=1, sticky="nsew")      # nsew: fills the whole cell
content.columnconfigure(0, weight=1)
content.rowconfigure(0, weight=1)

# the Text box is the part that absorbs the shrink
txt = tk.Text(content, wrap="word")
txt.insert("1.0", "This Text widget is sticky='nsew' in a weight=1 row/column,\n"
                  "so it grows and shrinks with the window.\n\n"
                  "The buttons below keep their size: they have no sticky and the\n"
                  "row they live in has weight=0.")
txt.grid(row=0, column=0, sticky="nsew", padx=8, pady=8)

btns = tk.Frame(content, bg="#118ab2")
btns.grid(row=1, column=0, sticky="e", padx=8, pady=(0, 8))
ttk.Button(btns, text="OK").grid(row=0, column=0, padx=4)
ttk.Button(btns, text="Cancel").grid(row=0, column=1, padx=4)

root.mainloop()
