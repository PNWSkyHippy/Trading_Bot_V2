Step by step:


"Total is " is a string → text

The + you used here is trying to join text with a number, and Python doesn’t allow that mix.

So in Python’s mind:


5 (number) is different from "5" (text)
99.9 (number) is different from "99.9" (text)

For math, Python wants numbers with numbers. For + with strings, it wants text with text.
