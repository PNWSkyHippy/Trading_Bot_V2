You’ve already spotted two of the biggest feel-shifts:


Print vs C-style printf
In Python you’re using print("string") (no format specifiers like %d unless you choose formats), and it’s a normal function call, not a special construct.

Indentation instead of braces
You’re exactly right:
In C you’d have:

if (condition) {
    // block
}
In Python it’s more like:

if condition:
    # block (indentation defines the scope)
The indentation is not just style; it’s the structure. If the indent is wrong, the logic is wrong.
