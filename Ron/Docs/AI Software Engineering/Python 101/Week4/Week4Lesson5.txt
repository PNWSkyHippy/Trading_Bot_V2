Imagine we’re writing a little Python program that talks about your favorite band 🎵

Python is working with text here, not numbers. In programming, we call this kind of thing a data type.



Data type = a category of data (like text, number, True/False) that decides what you can do with it.



So "Metallica" is text, and text belongs to the string data type.

In Python, that text data type is called a string. You make a string by putting text inside quotes:

Python
"Hello"
'Python'
"Metallica"
Single quotes ' ' or double quotes " " both work the same for strings in Python.

Exactly right — in quotes ⇒ it’s a string 🎯


Now let’s use that with variables and the + operator.


In Python, + between strings means: glue the text together (this is called concatenation).


Example:

Python
first = "Metallica"
second = " rocks"
print(first + second)
This takes the text in first and the text in second and sticks them together into one longer string.

Now let’s make two strings and glue them ourselves.


Remember:


Put text in quotes → string
Use + between strings → join them with no extra spaces added automatically

For example:

Python

song = "Nothing Else Matters"
print(artist + " - " + song)
