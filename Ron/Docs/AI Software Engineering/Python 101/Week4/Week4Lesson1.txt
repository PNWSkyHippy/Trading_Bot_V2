Say we do 11 divided by 4.


11 / 4 → 2.75
/ gives the full exact result, which can be a decimal.
11 // 4 → 2

11 − 8 = 3 leftover

So:


/ → exact result (integer + decimal part together, like 2.75)
// → whole-number part only (the quotient when you think in full groups), like 2
% → remainder only (the leftover), like 3
