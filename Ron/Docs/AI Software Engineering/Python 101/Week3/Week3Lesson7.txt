Good try on that one, Ron — this is a subtle difference 👍


The story was:


Each ticket: 12
You buy: 4
Fee added to the whole order: +3

So in math steps:


Ticket total: 12 * 4
Then add the fee: + 3

The Python line that does both steps inside print() is:

Python
print(12 * 4 + 3)
Python first does 12 * 4 (because * comes before +), gets 48, then adds 3, so the result is 51, and print(...) shows 51.

The one you chose:

Python
print(12 * 4) + 3
print(12 * 4) prints 48
then Python tries to do + 3 outside of print(), which doesn’t make sense there and will cause an error.

So the key idea:

➡️ All the math should live inside the parentheses of print( ... ).
