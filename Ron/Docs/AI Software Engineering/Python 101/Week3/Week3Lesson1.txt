In this course, the rule I want you to lock in is:



A code block in Python = a group of lines that all start with the same indentation.



For our if/else:

Python
if age < 12:
    print("child price")
else:
    print("regular price")
Visually:


if age < 12: and else: start at the left edge (no indent) → they’re not inside anything.
Both print(...) lines have the same 4-space indent → each one belongs to its own block.

If one print had 4 spaces and the other had 3 or 5, Python would complain.

Make sense so far: “everything in the block must line up under each other with the same indent”?

Let’s lock in one more key symbol pair: = vs ==.


= means “put this value into the variable” (assignment)
age = 20      # set age to 20
== means “is this equal to…?” (a question used in if)
if age == 20:
    print("age is twenty")

So: = changes a value, == just checks a value.

Quick check in your own words (short is fine):

That distinction is super important for if statements.
