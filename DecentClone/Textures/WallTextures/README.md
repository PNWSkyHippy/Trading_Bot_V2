# Tunnel texture five-packs

Each image is a 2048 x 1024 JPEG. The shared basename identifies the pack and the two-digit suffix identifies sequence order.

- alien-clouds-01.jpg through alien-clouds-05.jpg
- alien-ocean-01.jpg through alien-ocean-05.jpg
- deep-space-01.jpg through deep-space-05.jpg

Apply each pack in order 01, 02, 03, 04, 05 and repeat. The fifth image is also blended to return to the first image.

UV orientation confirmed from the game code: image width wraps around the tunnel circumference; image height spans one tunnel section from end to end.
