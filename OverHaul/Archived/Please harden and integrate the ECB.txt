Critical issue to solve first
=============================
The current backtester uses generic intraday time stops (~30m / 2h / 5h / 8h).
ECB is a 1h strategy whose thesis explicitly uses max_bars_hold = 24.
That means the generic time-stop framework will prematurely kill ECB trades and invalidate results.

Required architecture change:
- Add strategy-aware handling so ECB can define its own max hold / exit policy.
- Do NOT apply generic intraday time stops to ECB if they conflict with the strategy thesis.
- Preferred approach:
  - add a strategy flag/property such as:
      self.time_stop_profile = "strategy_defined"
    or
      self.disable_generic_time_stops = True
  - then backtester skips generic early/perf/hard time stops for this strategy
  - strategy-specific exits handle the hold duration instead

ECB hardening requirements
==========================

1. Rename strategy name to framework-safe snake_case
----------------------------------------------------
Change:
    self.strategy_name = "ECBStrategy"
To:
    self.strategy_name = "ecb_strategy"

2. Fix entry semantics: use entropy COLLAPSE event, not low-entropy state
-------------------------------------------------------------------------
Current logic fires on every bar where entropy remains below threshold:
    low_entropy & bias_up/down & regime & vol_ok

That can cause repeated entries inside the same persistent low-entropy regime.
The hypothesis says:
    “enter when entropy collapses below threshold”
So signal should be an event, not a state.

Implement:
- entropy_prev = entropy.shift(1)
- entropy_collapse = (entropy_prev >= entropy_thresh) & (entropy < entropy_thresh)

Use that event in entries:
- long_signal  = entropy_collapse & bias_up & bull_regime & vol_ok
- short_signal = entropy_collapse & bearish_bias & bear_regime & vol_ok

3. Add reset / re-arm logic to prevent repeated same-regime re-entry
--------------------------------------------------------------------
Need a way to avoid immediate re-entry until entropy has normalized again.

Add parameter:
    entropy_reset: float = 0.90

Preferred behavior:
- after an entropy-collapse entry, do not allow another entry in same direction
  until entropy has risen back above entropy_reset

If full stateful re-arm logic is too invasive, minimum acceptable fallback:
- require previous bar NOT already low_entropy
  i.e. use collapse cross only

4. Add explicit bias threshold parameter
----------------------------------------
Current:
    bias_up = rolling mean of up candles > 0.5

That is a bit loose.
Add parameter:
    bias_threshold: float = 0.55

Then:
- bias_up   = rolling_up_ratio >= bias_threshold
- bias_down = rolling_up_ratio <= (1 - bias_threshold)

Expose it as a parameter but do not over-optimize yet.

5. Add proper warmup / minimum bars discipline
----------------------------------------------
Need enough history for:
- entropy window
- ATR
- volatility filter MA
- 200-bar SMA

Create a clear MIN_BARS constant, something like:
    MIN_BARS = max(trend_ma_length + 20, vol_filter_len + 20, entropy_window + 20)

Use _check_enough_candles() consistently.

7. Implement true strategy-specific exit logic
----------------------------------------------
ECB thesis says:
- primary exit = 24-bar max hold
- SL/TP = ATR-based catastrophic exits / backstops
- continuation ends when entropy normalizes or regime flips

Implement check_custom_exit() for ECB.

Desired exit priority:
A. regime flip exit
   - long: close < macro_ma
   - short: close > macro_ma

B. entropy normalization exit

C. max bars hold exit

Important:

Do not fake max-hold logic without actual elapsed-bar knowledge.

If needed:

- pass bars_held through entry metadata / trade context
But keep implementation clean and consistent with existing framework style.

8. Structural stop metadata
---------------------------
ECB uses ATR stop from entry.
Store the absolute stop in metadata as:
    structural_stop_price

For long:
    close - atr * sl_atr_mult
For short:
    close + atr * sl_atr_mult

This lets executor/backtester use the intended stop architecture.
