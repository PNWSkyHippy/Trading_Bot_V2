Key constraints from the code
Fact	Impact on design
_check_price_still_moving() returns a ChecklistResult — can't return a payload	Flip logic must live in receive_signal(), not inside the check
_run_checklist() is in the hard-check list — it runs before we know if drift failed	Need a side-channel to carry live_price from the check to the caller
All hard/soft checks read direction from the payload dict	A shallow clone + p["direction"] = flipped automatically corrects every downstream check (wick, RSI, structural stop, trend, market context)
_check_momentum_phase() uses abs(dist_pct)	Negating distance_from_breakout_pct is safe — the magnitude check still fires correctly
structural_stop_price is side-specific	Must null it on flip; executor falls back to percent-based stop
momentum_val returns avg of last 5 bar pct-changes; < -0.5 → short in scanner	We use < 0 for the flip criterion — more sensitive, appropriate since we're detecting an in-progress reversal, not a setup
Architecture choice
_check_price_still_moving() stores the live price in self._drift_state (a dict that is wiped at the top of every receive_signal() call). receive_signal() checks that dict after a hard failure and, if non-empty, calls _try_direction_flip(). The flip returns the full Dict[str, Any] response or None.

Calling from inside _check_price_still_moving() would require it to run the checklist, build a payload, and call _inject_signal() — three responsibilities it doesn't own.

def _check_price_still_moving(self, p: Dict) -> ChecklistResult:
    sym       = p["symbol"]
    asset     = p.get("asset_class", "crypto")
    ref_price = float(p.get("current_price") or p.get("entry_price", 0))
    direction = p.get("direction", "long")

    if not self._scanner_ref:
        return ChecklistResult.fail(
            "Price re-verify impossible — scanner not wired to receiver"
        )
    if ref_price <= 0:
        return ChecklistResult.fail("current_price/entry_price is zero or missing")

    try:
        current = self._fetch_live_price_from_scanner(p)

        if not current:
            return ChecklistResult.skip(
                f"Could not fetch live price for {sym} — skipping price drift check"
            )

        drift_pct = ((current - ref_price) / ref_price) * 100

        if direction == "long" and drift_pct < -PRICE_DRIFT_MAX_PCT:
            # Stash for potential LONG→SHORT flip attempt in receive_signal()
            self._drift_state = {"live_price": current, "drift_pct": drift_pct}
            return ChecklistResult.fail(
                f"{sym} reversed {drift_pct:.2f}% from signal price "
                f"(limit -{PRICE_DRIFT_MAX_PCT}%)"
            )
        if direction == "short" and drift_pct > PRICE_DRIFT_MAX_PCT:
            # Stash for potential SHORT→LONG flip attempt in receive_signal()
            self._drift_state = {"live_price": current, "drift_pct": drift_pct}
            return ChecklistResult.fail(
                f"{sym} reversed +{drift_pct:.2f}% from signal price "
                f"(limit +{PRICE_DRIFT_MAX_PCT}%)"
            )

        return ChecklistResult.ok(f"{sym} still moving (drift={drift_pct:+.2f}%)")
    except Exception as e:
        return ChecklistResult.fail(f"Price re-verify exception: {e}")

def _try_direction_flip(
    self,
    payload: Dict[str, Any],
    live_price: float,
    drift_pct: float,
    signal_age_sec: float,
) -> Optional[Dict[str, Any]]:
    """
    Called when _check_price_still_moving() rejects due to adverse drift.

    Evaluates 3 criteria for a direction reversal; requires 2/3 to proceed.
    If criteria pass, clones the payload, mutates it for the flipped direction,
    and re-runs the full checklist.  Returns the injection result dict on success,
    or None to let the caller reject as normal.

    Works symmetrically for LONG→SHORT and SHORT→LONG.
    """
    sym        = payload.get("symbol", "?")
    orig_dir   = payload.get("direction", "long")
    flipped    = "short" if orig_dir == "long" else "long"

    # ── Evaluate 3 flip criteria ─────────────────────────────────────────
    criteria_met = 0

    # 1) Volume still elevated — confirms a real move, not a liquidity gap
    vol = float(payload.get("volume_spike", 0))
    c1  = vol >= VOLUME_SPIKE_MIN
    if c1:
        criteria_met += 1

    # 2) Momentum has reversed sign
    momentum = float(payload.get("momentum_score", 0))
    c2 = (momentum < 0) if orig_dir == "long" else (momentum > 0)
    if c2:
        criteria_met += 1

    # 3) Live price crossed candle_open — confirms bearish/bullish body forming
    candle_open = payload.get("candle_open")
    if candle_open is not None:
        co = float(candle_open)
        c3 = (live_price < co) if orig_dir == "long" else (live_price > co)
    else:
        c3 = False
    if c3:
        criteria_met += 1

    logger.info(
        f"[BREAKOUT RECV] FLIP EVAL {sym}: {orig_dir.upper()}→{flipped.upper()} "
        f"criteria={criteria_met}/3  "
        f"vol={vol:.2f}x≥{VOLUME_SPIKE_MIN}:{c1}  "
        f"momentum={momentum:.3f} reversed:{c2}  "
        f"candle_open={float(candle_open):.4f if candle_open is not None else 'N/A'}  "
        f"live={live_price:.4f} body_confirms:{c3}"
    )

    if criteria_met < 2:
        logger.info(
            f"[BREAKOUT RECV] FLIP DENIED {sym}: only {criteria_met}/3 criteria met — "
            f"rejecting as original {orig_dir.upper()}"
        )
        return None

    # ── Build the flipped payload ────────────────────────────────────────
    p = dict(payload)   # shallow clone — all values are scalars or None

    p["direction"]     = flipped
    p["current_price"] = live_price
    p["entry_price"]   = live_price

    # move_pct: drift_pct already carries the correct sign for the new direction
    # (negative for LONG→SHORT, positive for SHORT→LONG)
    p["move_pct"] = round(drift_pct, 4)

    # distance_from_breakout_pct: negate to reflect the reversed relationship
    # to the original breakout level (_check_momentum_phase uses abs() so the
    # magnitude check is unaffected)
    dist = payload.get("distance_from_breakout_pct")
    if dist is not None:
        p["distance_from_breakout_pct"] = -float(dist)

    # structural_stop_price is strictly side-specific; the original side's stop
    # is now on the wrong side of the entry — null it so the executor computes
    # a fresh percent-based stop
    p["structural_stop_price"] = None

    logger.info(
        f"[BREAKOUT RECV] DIRECTION FLIP {sym}: {orig_dir.upper()}→{flipped.upper()} "
        f"(drift={drift_pct:+.2f}%, criteria_met={criteria_met}/3) "
        f"entry={live_price:.4f} move_pct={p['move_pct']:+.4f}%"
    )

    # ── Re-run full checklist on the mutated payload ─────────────────────
    hard_results, soft_results = self._run_checklist(p, signal_age_sec)

    hard_passed = all(
        r.status in (ChecklistResult.PASS, ChecklistResult.SKIP)
        for r in hard_results
    )
    hard_skips  = sum(1 for r in hard_results if r.status == ChecklistResult.SKIP)
    soft_passes = sum(1 for r in soft_results if r.status == ChecklistResult.PASS)
    soft_skips  = sum(1 for r in soft_results if r.status == ChecklistResult.SKIP)

    for r in hard_results:
        lvl = logging.WARNING if r.status == ChecklistResult.FAIL else logging.INFO
        logger.log(lvl, f"  [FLIP HARD] {r}")
    for r in soft_results:
        logger.info(f"  [FLIP SOFT] {r}")

    checklist_summary = {
        "hard_passed":       hard_passed,
        "hard_skipped":      hard_skips,
        "soft_passed":       soft_passes,
        "soft_skipped":      soft_skips,
        "failed_hard_check": next(
            (r.reason for r in hard_results if r.status == ChecklistResult.FAIL), None
        ),
        "direction_flip": f"{orig_dir}→{flipped}",
    }

    if not hard_passed:
        failed = next(r for r in hard_results if r.status == ChecklistResult.FAIL)
        logger.info(
            f"[BREAKOUT RECV] FLIP CHECKLIST REJECTED {sym} — {failed.reason}"
        )
        return {
            "accepted":            False,
            "execution_eligible":  True,
            "failure_class":       "flip_checklist_rejected",
            "reason":              f"Direction flip failed checklist: {failed.reason}",
            "trade_id":            None,
            "checklist":           checklist_summary,
        }

    logger.info(
        f"[BREAKOUT RECV] FLIP CHECKLIST PASSED {sym} — "
        f"injecting {flipped.upper()} "
        f"soft: {soft_passes} pass / {soft_skips} skip (advisory only)"
    )
    return self._inject_signal(p, checklist_summary)

Answers to the explicit design questions
Should flip also work SHORT→LONG?
Yes. The implementation above is fully symmetric. When a SHORT arrives and drift_pct > +PRICE_DRIFT_MAX_PCT, the stash is set. In _try_direction_flip(), criterion 2 checks momentum > 0 and criterion 3 checks live_price > candle_open. No separate code path needed — the orig_dir == "long" ternaries handle both sides.

Where to call it: inside _check_price_still_moving() or receive_signal()?
receive_signal(). The price-check method's contract is Dict → ChecklistResult. Making it also fetch live price, build payloads, re-run checklists, and inject signals would be the wrong layer. The _drift_state side-channel keeps the check method clean while giving the caller everything it needs without a second network round-trip.

What happens to structural_stop_price?
Nulled unconditionally. A long stop is below entry; a short stop is above entry. The original stop is now on the wrong side of the trade and would immediately fail _check_structural_stop() anyway. Nulling it lets the executor fall back to its percent-based stop, which is what happens for crypto signals already.

What happens to entry_price?
Updated to live_price alongside current_price. The signal was originally stamped at a different price; using that stale level as the entry reference for a freshly-detected reverse move would give the executor a nonsensical entry anchor.

# ── New imports in market_scanner.py ────────────────────────────────────────
import threading
from datetime import datetime, timezone
from typing import Optional, Callable

WIN_REENTRY_DELAY_SEC = 125   # 120s cooldown + 5s buffer

class MarketScanner:

    def __init__(self, ...):
        ...
        self._receiver_ref            = None           # set via set_reentry_receiver()
        self._pending_reentry: set    = set()          # guard against duplicate timers
        self._pending_lock            = threading.Lock()

    def set_reentry_receiver(self, receiver) -> None:
        self._receiver_ref = receiver

    # ── Public: called from the trade-close thread ───────────────────────────
    def schedule_reentry(self, symbol: str, exit_price: float, direction: str) -> None:
        """
        Called by bot_engine's win callback from the position monitor thread.
        Never touches scanner state — only creates a Timer.
        """
        with self._pending_lock:
            if symbol in self._pending_reentry:
                logger.info(f"[REENTRY] {symbol}: already pending — skipped duplicate")
                return
            self._pending_reentry.add(symbol)

        t = threading.Timer(
            WIN_REENTRY_DELAY_SEC,
            self._safe_reentry_scan,
            args=[symbol, exit_price, direction],
        )
        t.daemon = True
        t.start()
        logger.info(
            f"[REENTRY] {symbol} {direction} re-entry scan "
            f"scheduled in {WIN_REENTRY_DELAY_SEC}s"
        )

    # ── Internal: fires on Timer thread (daemon) ─────────────────────────────
    def _safe_reentry_scan(self, symbol: str, exit_price: float, direction: str) -> None:
        with self._pending_lock:
            self._pending_reentry.discard(symbol)
        try:
            self._do_reentry_scan(symbol, exit_price, direction)
        except Exception as e:
            logger.error(f"[REENTRY] {symbol}: scan failed: {e}", exc_info=True)

    def _do_reentry_scan(self, symbol: str, exit_price: float, direction: str) -> None:
        """
        Synthesizes a re-entry signal from live price and feeds it to the receiver.

        The receiver's full checklist still runs:
          - freshness:        always passes (timestamp = now)
          - no open position: naturally enforced
          - cooldown:         120s win cooldown has expired (we waited 125s)
          - price moving:     verified here AND re-verified by receiver
          - volume_spike=1.0: triggers SKIP path (not FAIL) by receiver design
          - momentum phase:   bars_since_breakout=1 passes unless price chased >8%
        """
        if not self._receiver_ref:
            logger.warning("[REENTRY] No receiver wired — skipping")
            return

        asset_class   = "crypto" if "/" in symbol else "stock"
        current_price = self.get_current_price(symbol, asset_class)

        if not current_price:
            logger.info(f"[REENTRY] {symbol}: could not fetch live price — aborting")
            return

        # Price still moving in original direction? (0.3% tolerance for slippage/spread)
        drift_pct = ((current_price - exit_price) / exit_price) * 100
        if direction == "long"  and drift_pct < -0.3:
            logger.info(f"[REENTRY] {symbol}: reversed {drift_pct:.2f}% since exit — skip")
            return
        if direction == "short" and drift_pct >  0.3:
            logger.info(f"[REENTRY] {symbol}: reversed {drift_pct:+.2f}% since exit — skip")
            return

        payload = {
            "symbol":                      symbol,
            "asset_class":                 asset_class,
            "direction":                   direction,
            "entry_price":                 current_price,
            "current_price":               current_price,
            "move_pct":                    drift_pct,
            "volume_spike":                1.0,       # receiver SKIPs 1.0 (no history)
            "confidence":                  0.70,
            "escalation":                  1,         # treat as continuation, not fresh esc=0
            "timestamp":                   datetime.now(timezone.utc).isoformat(),
            "broker":                      "kraken" if asset_class == "crypto" else "alpaca",
            "bars_since_breakout":         1,
            "distance_from_breakout_pct":  abs(drift_pct),
            # Omit OHLC → _check_no_wick_rejection SKIPs (neutral)
            # Omit rsi/sma200 → soft checks SKIP (advisory only)
        }

        logger.info(
            f"[REENTRY] Injecting {symbol} {direction} @ ${current_price:.4f} "
            f"(exited @ ${exit_price:.4f}, drift={drift_pct:+.2f}%)"
        )

        result = self._receiver_ref.receive_signal(payload)
        accepted = result.get("accepted", False)
        logger.info(
            f"[REENTRY] {symbol}: {'ACCEPTED → trade_id=' + str(result.get('trade_id')) if accepted else 'REJECTED — ' + result.get('reason', '?')}"
        )

One flag worth calling out explicitly: _check_not_in_cooldown() in the receiver reads risk_manager._last_closed as a plain dict with no lock. If the Timer fires at exactly 120.000s and the position monitor hasn't finished writing _last_closed yet, the re-entry could slip through with a stale won=None. The 5s buffer (WIN_REENTRY_DELAY_SEC = 125) makes this a non-issue in practice, but if you want to be rigorous, a threading.Lock on _last_closed is the clean fix.
